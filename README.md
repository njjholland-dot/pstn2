# PSTN2: Next Generation Phone Network

**Website:** https://pstn2.org · **Source:** https://github.com/njjholland-dot/pstn2 · **Protocol:** v1.1

PSTN2 is an open industry proposal from Comms Council UK. It brings caller ID verification, end-to-end encryption, direct routing and real-time emergency location to the UK phone network. Communication Providers (CPs) implement it at the edge, at their own pace, and it needs **no central database**.

## The key idea: who has this number?

Every call starts with that question. PSTN2 answers it without a central database (~£2m to build and ~£600k a year to run), because the data already exists:

1. **Cache:** has this CP looked the number up recently?
2. **Ofcom's S1–S9 numbering lists**, plus one new field, the *Range Holder URL*. The longest matching block gives the Range Holder.
3. **Ask the Range Holder:** `GET {url}/pstn2/v1/numbers/{digits}`. It answers `held`, or `redirect` if the number has been ported.
4. **Follow the redirect** to the CP that now serves the number.
5. **Cache the answer** and go direct next time. Any response can say `cache.invalidate`, so stale entries correct themselves.

Watch it: [Who Has This Number?](https://pstn2.org/src/distributed-database/) · [Test Harness: Live Demo](https://pstn2.org/src/test-harness/) · Test against it: [pstn2.org/testcp](https://pstn2.org/testcp/)

## What's here

| Path | Contents |
|---|---|
| `animations/` | Homepage and 10 narrated, broadcast-grade presentations on a shared player (`animations/shared/README.md`) |
| `code/typescript`, `code/python`, `code/go` | SDKs v1.1, five examples each, unit and integration tests |

| `test-environment/` | Shared fixtures, a dependency-free mock network (three CPs and Ofcom), and the conformance suite |

## Quick start

```bash
# Prove everything agrees: reference engine + 3 SDK test suites + 15 examples
test-environment/conformance/run.sh

# Run a local network of three CPs plus Ofcom, then any example against it
node test-environment/mock-network/server.mjs
cd code/typescript && npm ci && npm run example:05
cd code/python && python3 -m venv .venv && .venv/bin/pip install -e '.[dev]' && .venv/bin/python examples/05_number_discovery.py
cd code/go && go run ./examples/05-number-discovery

# Talk to the live test CP
PSTN2_NETWORK=live npm run example:05          # from code/typescript
```

To view the presentations locally:

```bash
python3 -m http.server 8000 --directory animations
```

Then open http://localhost:8000/.

## Presenting

Every presentation:
- plays full screen at 16:9 with pre-rendered UK narration and captions;
- works offline once it has loaded.

| Key or option | Action |
|---|---|
| `Space` | play/pause |
| `←` `→` | change scene |
| `F` | full screen |
| `C` | captions |
| `M` | mute |
| `?kiosk=1` | loop for exhibition stands |

## Maintaining

- **Narration:** edit `narration.json`, then run `node tools/narrate/build-narration.mjs <deck>`. The best installed en-GB voice is chosen automatically; set `PSTN2_VOICE` to pick one.
- **Docs:** `python3 tools/render-docs.py` renders `docs/*.md`. Pass other paths explicitly.
- **Deploy:** `./deploy.sh --stage-only` (local build) or `./deploy.sh` (needs `PSTN2_FTP_PASSWORD`).
- **Guidance for AI-assisted work:** `Claude.md`.
