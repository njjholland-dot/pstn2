Version: 1.0

Date: 2025-12-01

Target Audience: System Administrators, Infrastructure Engineers

Overview

This guide describes deploying a MAP (Managed Access Provider) on your own infrastructure using open-source components. This approach provides full control, data sovereignty, and lower operational costs at scale compared to cloud deployment.

When to Choose On-Premises

✅ Good For:
  • Full Service MAPs with existing data centers
  • Large-scale operations (>1M calls/day)
  • Regulatory requirements (data residency)
  • Organizations with strong in-house operations teams
  • Cost-conscious deployments at scale
❌ Not Ideal For:
  • Startups or small operations
  • Limited technical staff
  • Rapid time-to-market requirements
  • Global multi-region deployments
  • Variable/unpredictable load

Hardware Requirements

Small Deployment (1-50 Downstream CPs)

| Component | Specs | Quantity | Notes |

|-----------|-------|----------|-------|

| Load Balancer | 4 CPU, 8GB RAM, 100GB SSD | 2 | HAProxy, high availability |

| API Servers | 8 CPU, 16GB RAM, 200GB SSD | 3 | Docker containers |

| Database (Primary) | 16 CPU, 64GB RAM, 1TB NVMe SSD | 1 | PostgreSQL 15+ |

| Database (Replica) | 16 CPU, 64GB RAM, 1TB NVMe SSD | 1 | Read replica |

| Redis Cache | 8 CPU, 32GB RAM, 500GB SSD | 2 | Primary + replica |

| Monitoring | 4 CPU, 16GB RAM, 500GB SSD | 1 | Prometheus + Grafana |

| Logging | 8 CPU, 32GB RAM, 2TB SSD | 1 | ELK stack |

| Total Servers | - | 11 | - |

Estimated Cost: $5,000-$15,000 (hardware) + $500-$1,000/month (power, cooling, bandwidth)

Medium Deployment (50-500 Downstream CPs)

| Component | Specs | Quantity | Notes |

|-----------|-------|----------|-------|

| Load Balancer | 8 CPU, 16GB RAM, 200GB SSD | 2 | HAProxy |

| API Servers | 16 CPU, 32GB RAM, 500GB SSD | 5-10 | Scale as needed |

| Database (Primary) | 32 CPU, 128GB RAM, 2TB NVMe SSD | 1 | PostgreSQL |

| Database (Replicas) | 32 CPU, 128GB RAM, 2TB NVMe SSD | 2 | Read replicas |

| Redis Cache | 16 CPU, 64GB RAM, 1TB SSD | 3 | 1 primary + 2 replicas |

| Monitoring | 8 CPU, 32GB RAM, 1TB SSD | 2 | HA Prometheus |

| Logging | 16 CPU, 64GB RAM, 5TB SSD | 2 | ELK cluster |

| Total Servers | - | 18-23 | - |

Estimated Cost: $20,000-$50,000 (hardware) + $2,000-$5,000/month (operations)

Deployment Steps

Step 1: Prepare Servers

<h1 id="on-all-servers-as-root">On all servers (as root)</h1>


<h1 id="update-system">Update system</h1>


apt update && apt upgrade -y



<h1 id="install-essentials">Install essentials</h1>


apt install -y curl wget git vim htop net-tools



<h1 id="configure-ntp-for-time-synchronization">Configure NTP for time synchronization</h1>


apt install -y chrony


systemctl enable chrony


systemctl start chrony



<h1 id="configure-firewall-ufw">Configure firewall (UFW)</h1>


ufw allow 22/tcp     # SSH


ufw allow 80/tcp     # HTTP


ufw allow 443/tcp    # HTTPS


ufw enable



<h1 id="disable-swap-recommended-for-databases">Disable swap (recommended for databases)</h1>


swapoff -a


sed -i '/swap/d' /etc/fstab



<h1 id="set-up-log-rotation">Set up log rotation</h1>


cat > /etc/logrotate.d/map << EOF


/var/log/map/*.log {


    daily


    rotate 30


    compress


    delaycompress


    notifempty


    create 0640 www-data www-data


    sharedscripts


}


EOF

Step 2: Install Docker

<h1 id="install-docker">Install Docker</h1>

curl -fsSL https://get.docker.com -o get-docker.sh


sh get-docker.sh



<h1 id="add-user-to-docker-group">Add user to docker group</h1>


usermod -aG docker $USER



<h1 id="install-docker-compose">Install Docker Compose</h1>


apt install -y docker-compose



<h1 id="enable-docker-service">Enable Docker service</h1>


systemctl enable docker


systemctl start docker

Step 3: Set Up PostgreSQL (Primary)

<h1 id="install-postgresql">Install PostgreSQL</h1>

apt install -y postgresql-15 postgresql-contrib-15



<h1 id="configure-postgresql">Configure PostgreSQL</h1>


cat > /etc/postgresql/15/main/postgresql.conf << EOF


<h1 id="connection-settings">Connection settings</h1>


listen_addresses = '*'


max_connections = 500



<h1 id="memory-settings-adjust-based-on-ram">Memory settings (adjust based on RAM)</h1>


shared_buffers = 16GB           # 25% of RAM


effectivecachesize = 48GB     # 75% of RAM


work_mem = 32MB


maintenanceworkmem = 2GB



<h1 id="write-ahead-log-settings">Write-ahead log settings</h1>


wal_level = replica


maxwalsenders = 5


walkeepsize = 1GB


hot_standby = on



<h1 id="performance-settings">Performance settings</h1>


randompagecost = 1.1          # For SSD


effectiveioconcurrency = 200  # For SSD


checkpointcompletiontarget = 0.9


EOF



<h1 id="configure-authentication">Configure authentication</h1>


cat > /etc/postgresql/15/main/pg_hba.conf << EOF


<h1 id="type-database-user-address-method">TYPE  DATABASE        USER            ADDRESS                 METHOD</h1>


local   all             postgres                                peer


host    all             all             10.0.0.0/8              scram-sha-256


host    replication     replicator      10.0.0.0/8              scram-sha-256


EOF



<h1 id="restart-postgresql">Restart PostgreSQL</h1>


systemctl restart postgresql



<h1 id="create-replication-user">Create replication user</h1>


sudo -u postgres psql << EOF


CREATE USER replicator WITH REPLICATION ENCRYPTED PASSWORD 'securereplicationpassword';


EOF



<h1 id="create-map-database">Create MAP database</h1>


sudo -u postgres createdb mapdb


sudo -u postgres createuser mapadmin


sudo -u postgres psql << EOF


ALTER USER mapadmin WITH ENCRYPTED PASSWORD 'secureadminpassword';


GRANT ALL PRIVILEGES ON DATABASE mapdb TO mapadmin;


EOF



<h1 id="initialize-schema">Initialize schema</h1>


sudo -u postgres psql -d mapdb -f /path/to/schema.sql

Step 4: Set Up PostgreSQL (Replica)

<h1 id="on-replica-server">On replica server</h1>


<h1 id="stop-postgresql">Stop PostgreSQL</h1>

Step 5: Set Up Redis Cluster

<h1 id="on-primary-redis-server">On primary Redis server</h1>


<h1 id="install-redis">Install Redis</h1>


apt install -y redis-server



<h1 id="configure-redis">Configure Redis</h1>


cat > /etc/redis/redis.conf << EOF


<h1 id="network">Network</h1>


bind 0.0.0.0


port 6379


protected-mode yes


requirepass secureredispassword



<h1 id="memory">Memory</h1>


maxmemory 24gb


maxmemory-policy allkeys-lru



<h1 id="persistence">Persistence</h1>


save 900 1


save 300 10


save 60 10000


appendonly yes



<h1 id="replication">Replication</h1>


replicaof <replica-will-set-this>


masterauth secureredispassword


EOF



<h1 id="restart-redis">Restart Redis</h1>


systemctl restart redis



<h1 id="on-replica-redis-servers">On replica Redis servers</h1>


cat >> /etc/redis/redis.conf << EOF

EOF



systemctl restart redis

Step 6: Set Up Load Balancers (HAProxy)

<h1 id="on-both-load-balancer-servers">On both load balancer servers</h1>


<h1 id="install-haproxy-and-keepalived">Install HAProxy and Keepalived</h1>


apt install -y haproxy keepalived



<h1 id="configure-haproxy">Configure HAProxy</h1>


cat > /etc/haproxy/haproxy.cfg << EOF


global


    log /dev/log local0


    log /dev/log local1 notice


    chroot /var/lib/haproxy


    stats socket /run/haproxy/admin.sock mode 660 level admin


    stats timeout 30s


    user haproxy


    group haproxy


    daemon



    # SSL/TLS settings


    ssl-default-bind-ciphers ECDHE-ECDSA-AES128-GCM-SHA256:ECDHE-RSA-AES128-GCM-SHA256


    ssl-default-bind-options ssl-min-ver TLSv1.2 no-tls-tickets



defaults


    log     global


    mode    http


    option  httplog


    option  dontlognull


    timeout connect 5000


    timeout client  50000


    timeout server  50000



<h1 id="stats-page">Stats page</h1>


listen stats


    bind *:8404


    mode http


    stats enable


    stats uri /stats


    stats refresh 30s


    stats auth admin:securestatspassword



<h1 id="frontend-https">Frontend (HTTPS)</h1>


frontend https_front


    bind *:443 ssl crt /etc/ssl/certs/map-certificate.pem


    bind *:80


    redirect scheme https code 301 if !{ ssl_fc }



    # Rate limiting


    stick-table type ip size 100k expire 30s store httpreqrate(10s)


    http-request track-sc0 src


    http-request deny denystatus 429 if { schttpreqrate(0) gt 100 }



    # Security headers


    http-response set-header Strict-Transport-Security "max-age=31536000; includeSubDomains"


    http-response set-header X-Frame-Options "DENY"


    http-response set-header X-Content-Type-Options "nosniff"



    defaultbackend apiservers



<h1 id="backend-api-servers">Backend (API Servers)</h1>


backend api_servers


    balance roundrobin


    option httpchk GET /health


    http-check expect status 200



    server api1 10.0.1.10:3000 check inter 5s rise 2 fall 3


    server api2 10.0.1.11:3000 check inter 5s rise 2 fall 3


    server api3 10.0.1.12:3000 check inter 5s rise 2 fall 3


EOF



<h1 id="configure-keepalived-primary">Configure Keepalived (Primary)</h1>


cat > /etc/keepalived/keepalived.conf << EOF


vrrpscript chkhaproxy {


    script "killall -0 haproxy"


    interval 2


    weight 2


}



vrrpinstance VI1 {


    interface eth0


    state MASTER


    virtualrouterid 51


    priority 101  # Higher on primary


    advert_int 1



    authentication {


        auth_type PASS


        authpass securevrrp_password


    }



    virtual_ipaddress {


        10.0.0.100/24  # Virtual IP


    }



    track_script {


        chk_haproxy


    }


}


EOF



<h1 id="on-backup-load-balancer-set-priority-to-100-instead-of-101">On backup load balancer, set priority to 100 instead of 101</h1>



<h1 id="start-services">Start services</h1>


systemctl enable haproxy keepalived


systemctl restart haproxy keepalived

Step 7: Deploy API Servers

<h1 id="on-each-api-server">On each API server</h1>


<h1 id="create-docker-compose-yml">Create docker-compose.yml</h1>


cat > /opt/map/docker-compose.yml << EOF


version: '3.8'



services:


  api:


    image: map-api-server:latest


    container_name: map-api


    restart: always


    ports:


      - "3000:3000"


    environment:


      - NODE_ENV=production


      - PORT=3000


      - DB_HOST=10.0.2.10


      - DB_PORT=5432


      - DB_NAME=mapdb


      - DB_USER=mapadmin


      - DBPASSWORD=secureadmin_password


      - REDIS_HOST=10.0.3.10


      - REDIS_PORT=6379


      - REDISPASSWORD=secureredis_password


      - MASTERKEYFILE=/secrets/master-key.txt


    volumes:


      - /opt/map/secrets:/secrets:ro


      - /var/log/map:/var/log/map


    logging:


      driver: "json-file"


      options:


        max-size: "10m"


        max-file: "10"



  nginx:


    image: nginx:latest


    container_name: map-nginx


    restart: always


    ports:


      - "80:80"


    volumes:


      - /opt/map/nginx.conf:/etc/nginx/nginx.conf:ro


    depends_on:


      - api



networks:


  default:


    driver: bridge


EOF



<h1 id="create-nginx-config">Create nginx config</h1>


cat > /opt/map/nginx.conf << EOF


worker_processes auto;



events {


    worker_connections 4096;


}



http {


    upstream api_backend {


        server api:3000;


    }



    server {


        listen 80;



        location /health {


            proxypass http://apibackend/health;


            proxyhttpversion 1.1;


            proxysetheader Connection "";


        }



        location / {


            proxypass http://apibackend;


            proxyhttpversion 1.1;


            proxysetheader Host \$host;


            proxysetheader X-Real-IP \$remote_addr;


            proxysetheader X-Forwarded-For \$proxyaddxforwardedfor;


            proxysetheader X-Forwarded-Proto \$scheme;



            # Timeouts


            proxyconnecttimeout 5s;


            proxysendtimeout 60s;


            proxyreadtimeout 60s;


        }


    }


}


EOF



<h1 id="start-services">Start services</h1>


cd /opt/map


docker-compose up -d

Step 9: Configure SSL/TLS Certificates

<h1 id="install-certbot">Install certbot</h1>

apt install -y certbot



<h1 id="obtain-certificate-use-dns-or-http-challenge">Obtain certificate (use DNS or HTTP challenge)</h1>


certbot certonly --standalone -d api.map.example.com --email ops@example.com --agree-tos



<h1 id="create-combined-pem-file-for-haproxy">Create combined PEM file for HAProxy</h1>


cat /etc/letsencrypt/live/api.map.example.com/fullchain.pem \


    /etc/letsencrypt/live/api.map.example.com/privkey.pem \


    > /etc/ssl/certs/map-certificate.pem



<h1 id="set-up-auto-renewal">Set up auto-renewal</h1>


cat > /etc/cron.daily/certbot-renew << EOF


#!/bin/bash


certbot renew --quiet --post-hook "cat /etc/letsencrypt/live/api.map.example.com/fullchain.pem /etc/letsencrypt/live/api.map.example.com/privkey.pem > /etc/ssl/certs/map-certificate.pem && systemctl reload haproxy"


EOF



chmod +x /etc/cron.daily/certbot-renew

Step 10: Set Up Automated Backups

<h1 id="install-restic">Install Restic</h1>

apt install -y restic



<h1 id="initialize-backup-repository-to-nas-or-s3">Initialize backup repository (to NAS or S3)</h1>


export RESTIC_REPOSITORY=/mnt/backup/map-backups


export RESTICPASSWORD=securebackup_password


restic init



<h1 id="create-backup-script">Create backup script</h1>


cat > /usr/local/bin/map-backup.sh << 'EOF'


#!/bin/bash



export RESTIC_REPOSITORY=/mnt/backup/map-backups


export RESTICPASSWORD=securebackup_password



<h1 id="backup-postgresql">Backup PostgreSQL</h1>


sudo -u postgres pg_dump mapdb | gzip > /tmp/mapdb-$(date +%Y%m%d).sql.gz



<h1 id="backup-with-restic">Backup with Restic</h1>


restic backup /tmp/mapdb-*.sql.gz \


              /opt/map/secrets \


              /etc/haproxy \


              /etc/postgresql



<h1 id="cleanup-old-backups-keep-last-30-days">Cleanup old backups (keep last 30 days)</h1>


restic forget --keep-daily 30 --prune



<h1 id="remove-temp-sql-dump">Remove temp SQL dump</h1>


rm /tmp/mapdb-*.sql.gz


EOF



chmod +x /usr/local/bin/map-backup.sh



<h1 id="schedule-daily-backup-at-3-am">Schedule daily backup at 3 AM</h1>


cat > /etc/cron.d/map-backup << EOF


0 3   * root /usr/local/bin/map-backup.sh >> /var/log/map-backup.log 2>&1


EOF

Comparison: On-Premises vs AWS

| Aspect | On-Premises | AWS |

|--------|-------------|-----|

| Capital Cost | High ($20K-$50K) | Low (pay-as-you-go) |

| Monthly Cost | Low ($2K-$5K) | Medium ($500-$2.5K) |

| Break-Even | ~12-18 months | N/A |

| Time to Deploy | 1-2 weeks | 2-4 hours |

| Scalability | Manual (buy hardware) | Automatic |

| Maintenance | Your team | AWS managed |

| Data Sovereignty | Complete control | AWS regions |

| Customization | Full control | Limited |

| High Availability | Your responsibility | Built-in |

Recommendation:
  • < 50 CPs: Use AWS (faster, easier)
  • 50-200 CPs: Either (depends on expertise)
  • > 200 CPs: Consider on-prem (cost savings)

Conclusion

On-premises deployment provides:
