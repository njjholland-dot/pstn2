# Emergency Services

How PSTN2 gives 999 and 112 call centres the caller’s current location in real time, instead of a daily batch file. The caller’s provider is found with PSTN2 number discovery, then asked with a signed location query (SPECIFICATION.md §8, §9).

Runs on the shared broadcast player (`../../shared/`, see its README). About 3.6 minutes of pre-rendered narration, 9 scenes.

## Scenes

1. **Every second counts** (`seconds`)
2. **Today: a daily batch file** (`batch`)
3. **Too vague to act on** (`precision`)
4. **PSTN2: location in real time** (`realtime`)
5. **Inside the location query** (`query`)
6. **Mobile: every location source** (`mobile`)
7. **Fixed lines: better records** (`fixed`)
8. **Minutes saved, lives saved** (`impact`)
9. **Where regulation is heading** (`regulation`)

## Files

- `narration.json`: the script (captions and voice)
- `scenes.js`: the animated diagram for each scene
- `deck.css`: deck-specific styles
- `audio/`: generated by `node tools/narrate/build-narration.mjs emergency-services`

Preview: `index.html?capture=1` with `window.__p2.show(i)` for QA; `#n` starts at scene n.
