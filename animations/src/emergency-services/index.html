The Life-or-Death Problem

When someone calls 999 or 112, every second counts. Emergency responders need accurate location information immediately. Lives depend on finding people quickly. Current systems often provide outdated or imprecise location data.

Current System Limitations

Today's emergency location system uses batch updates. CPs send location databases to emergency services once every 24 hours. This means the data can be up to a day old. If someone's location changed recently, the wrong information is sent.

Precision Problems

Current systems often provide only postcode area precision, which can cover several square kilometers. In urban areas, this might encompass dozens of buildings. Responders waste precious time searching. In rural areas, the problem is even worse.

PSTN2 Real-Time Location

PSTN2 provides real-time location queries. When a 999 call comes in, the terminating CP queries the originating CP immediately for current device location. The response includes GPS coordinates if available, accurate to within 10 meters.

The Query Process

Emergency call arrives at CP. CP identifies it as emergency based on the destination number. CP queries the originating network: what is the current location of this device? Originating CP checks its database and responds within milliseconds with the most recent location data.

Mobile Device Integration

For mobile devices, location can include GPS coordinates, cell tower information, and WiFi access point data. The originating CP aggregates this information from the device. All of this is available in real-time, not from yesterday's batch file.

Fixed Line Intelligence

Even for fixed lines, PSTN2 improves accuracy. Instead of just an address from last year's database, CPs can provide recently verified billing address, installation records, and customer-confirmed location information. All updated in real-time.

Response Time Impact

Real-time location data can reduce emergency response times by minutes. Studies show that in cardiac arrest cases, every minute of delay reduces survival chance by 10%. Faster response times directly translate to lives saved.

Regulatory Compliance

PSTN2 emergency location exceeds current regulatory requirements. The EU's eCall directive, US's E911, and UK's Advanced Mobile Location all envision real-time location. PSTN2 provides the infrastructure to deliver it across all carriers.
