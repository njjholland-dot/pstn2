# MAP Architecture

How Managed Access Providers (MAPs) host PSTN2 for smaller providers, while each provider stays in control of its numbers through Ofcom’s lists and its Range Holder URL.

Runs on the shared broadcast player (`../../shared/`, see its README). About 4.0 minutes of pre-rendered narration, 11 scenes.

## Scenes

1. **The small provider challenge** (`challenge`)
2. **Managed Access Providers** (`maps`)
3. **What a MAP provides** (`services`)
4. **Ways to connect** (`integration`)
5. **A competitive market** (`market`)
6. **What it costs** (`cost`)
7. **The provider stays in control** (`trust`)
8. **Regulatory oversight** (`regulation`)
9. **Network effects** (`scale`)
10. **A rural provider** (`example`)
11. **PSTN2 for everyone** (`everyone`)

## Files

- `narration.json`: the script (captions and voice)
- `scenes.js`: the animated diagram for each scene
- `deck.css`: deck-specific styles
- `audio/`: generated by `node tools/narrate/build-narration.mjs map-architecture`

Preview: `index.html?capture=1` with `window.__p2.show(i)` for QA; `#n` starts at scene n.
